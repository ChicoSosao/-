# # Corporate Fleet Management System

## Концепция системы
Система предназначена для комплексной автоматизации процессов управления корпоративным автотранспортом, снижения операционных издержек (TCO) и прозрачного распределения ТС между сотрудниками.

### Ключевой функционал:
* **Учет ТС:** Цифровые паспорта машин, контроль пробега, отслеживание технического статуса.
* **Управление заявками:** Оперативное бронирование автомобилей сотрудниками и согласование поездок диспетчерами.
* **Мониторинг расходов:** Учет затрат на топливо (ГСМ), ремонты, штрафы и страхование (ОСАГО/КАСКО).
* **Аналитика:** Автоматический расчет общей стоимости владения (TCO) и коэффициента загрузки автопарка.

## Технологический стек
* **Backend:** Python 3.11, FastAPI, Pydantic v2, SQLAlchemy / SQLModel
* **Database & Cache:** PostgreSQL, Redis
* **Task Broker:** Celery (отложенные уведомления о необходимости ТО и продлении страховки)
* **Frontend:** React, TypeScript, TailwindCSS
* **DevOps:** Docker, Docker Compose, GitHub Actions

## Инструкции по локальному развертыванию
1. Клонируйте репозиторий: `git clone https://github.com`
2. Создайте файл конфигурации: `cp .env.example .env` (заполните параметры подключения к БД и Redis).
3. Соберите и запустите контейнеры: `docker-compose up --build -d`
4. Выполните миграции базы данных: `docker-compose exec backend alembic upgrade head`
5. Сервисы доступны по адресам:
   * Интерфейс (Frontend): `http://localhost:3000`
   * Документация API (Swagger): `http://localhost:8000/docs`
