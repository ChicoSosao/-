# # Corporate Fleet Management System
# Подсистема учета прохождения производственных практик и стажировок (InternshipFlow)

## Концепция системы
Система предназначена для комплексной автоматизации, координации и цифрового контроля процессов прохождения студентами учебных, производственных и преддипломных практик, а также внешних стажировок.

### Основные модули:
- **Личный кабинет студента:** Подача заявок на стажировки, генерация договоров, ведение цифрового дневника и отправка отчетов.
- **Панель координатора вуза:** Управление реестром баз практик, автоматическое распределение по квотам, верификация отчетных документов.
- **Портал наставника от предприятия:** Публикация вакантных мест, оценка KPI стажеров, формирование отзывов и характеристик.

## Технологический стек
- **Backend:** Node.js (v20 LTS), NestJS framework, TypeScript (строгая типизация, модульная архитектура, встроенная валидация).
- **Frontend:** TypeScript, React, TailwindCSS (адаптивный SPA-интерфейс для мобильных устройств студентов и десктопов координаторов).
- **СУБД:** PostgreSQL 16 (хранение реляционных данных о пользователях, договорах и оценках).
- **ORM:** Prisma ORM (миграции схемы данных, безопасное и типизированное взаимодействие с СУБД).
- **Контейнеризация:** Docker, Docker Compose.

## Инструкции по развертыванию (Локально)

### Предварительные требования
- Установленный [Docker Desktop](https://docker.com) и плагин Docker Compose.

### Быстрый запуск
1. Клонируйте репозиторий проекта:
   ```bash
   git clone https://github.com
   cd internship-flow
   ```
2. Скопируйте файл конфигурации окружения:
   ```bash
   cp .env.example .env
   ```
3. Запустите проект в Docker-контейнерах:
   ```bash
   docker-compose up --build -d
   ```
4. Выполните генерацию Prisma-клиента и примените миграции к СУБД:
   ```bash
   docker-compose exec backend npx prisma migrate dev
   ```
5. Информационная система будет доступна по адресам:
   - Frontend SPA: `http://localhost:5173`
   - Backend REST API (Swagger): `http://localhost:3000/api/docs`
